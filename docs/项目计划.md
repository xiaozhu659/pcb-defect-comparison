# 项目计划

## 一、选题

**工业 PCB 表面缺陷检测:传统检测模型与视觉大模型的对比**

数据采用公开的 PCB 缺陷数据集(HRIPCB 格式):693 张板图、6 类缺陷、
2953 个标注框。选择这个方向的原因有三点:

1. 工业质检是视觉检测的真实落地场景,与本人的机电/自动化背景相关;
2. 缺陷在原图中极其微小(面积中位数不到整图的 0.04%),
   是**微小目标检测**的典型问题,正好能体现两种技术路线的能力边界;
3. 数据集公开、体积小(约 900 MB)、许可清晰(MIT),实验可复现。

本项目不属于考核给出的三个参考项目方向,数据、任务与实验设计均为自主选择。

## 二、两种方案

| | 传统深度学习方案 | 视觉 / 多模态大模型方案 |
| --- | --- | --- |
| 模型 | YOLO11n 检测 + SAM 2.1 分割 | DeepSeek `deepseek-flash`(支持图片输入) |
| 是否需要训练 | 需要,用 555 张标注图训练 | 不需要,零样本直接调用 |
| 输出 | 缺陷类别、位置框、分割掩膜、精确面积 | 缺陷类别、大致位置描述、严重程度 |
| 优势 | 精度高、速度快、可量化 | 无需标注、能给出自然语言判断与建议 |

## 三、考核要求对照

| 要求 | 落地方式 |
| --- | --- |
| 同一视觉问题、同一组输入 | 两种方案都跑同一批 138 张验证集图片 |
| 传统方案用 YOLO / SAM 完成视觉任务 | YOLO 检测 + 以检测框为提示的 SAM 分割 |
| 大模型处理同样的输入 | 视觉 API 对同一批图片做判断,输出结构化 JSON |
| 并排展示与方案对比 | 量化指标表 + 并排可视化图 |
| 说明使用体验与适用场景 | 实验结果分析章节 |
| 仓库持续提交、保留开发历史 | 按天分阶段提交 |
| 一份文档说明(含个人感悟) | docs/项目说明.md |
| 一个运行视频 | 演示两种方案的推理与对比结果 |
